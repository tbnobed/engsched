Keep credentials out of the browser

Store tokens in your server’s secret manager or protected environment. Never embed keys in browser code, public code, URLs, or logs.

This example uses a placeholder, not a live key. Select tickets:read to use it. See the documentation for complete endpoint contracts.

Know the boundaries

  • Scopes confer access across all tickets and schedules, not just the owner’s records. Write scopes do not imply read access; select each permission explicitly.
  • Keys stop working if their owner loses administrator access or is deleted.
  • API mutations do not send emails or run AI.
  • Ticket DELETE archives a ticket. Schedule DELETE permanently removes one entry.
  • Rotation immediately revokes the old key and preserves its original expiry. Update your integration immediately.
